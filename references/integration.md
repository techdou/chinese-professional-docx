# 与其他 Agent 能力协作

本 Skill 提供中文文档的通用样式、母版、确定性缩进修复和 QA 闸门。由宿主的 DOCX 工具负责复杂表格、批注、修订、公式、脚注和特殊分节；不要把原文逐段变成纯文本再重建。

内容写作、学术润色、事实核验由相应能力承担：先完成获授权的内容工作，再应用排版，最后验证。用户仅要排版时，不顺带润色或调整论证。科研绘图由绘图能力生成，再插入 Word；本 Skill 不自行重画数据或把示意图当实验结果。

多产物任务按文件分工：Word 部分使用本 Skill，PPT/XLSX/PDF-only 部分使用相应能力。模板冲突优先按指定模板路线处理，而不是让多个 Skill 依次覆盖样式。

执行前用 `scripts/doctor.py` 只读探测运行时。缺少 Python 包时，优先现成环境；获授权后才在隔离环境安装，不要求用户交出 API key。网络可用性不是本地排版的前提。

安装目录不是当前工作目录。通过宿主给出的 SKILL.md 路径定位 Skill 根目录，解析其 `.venv` 解释器（若存在），用绝对路径调用脚本。所有输入与输出仍在用户实际工作区，不能写入 assets 覆盖母版。

`agents/openai.yaml` 是可选 OpenAI 客户端适配，不是通用规范必需字段。保留隐式调用；不添加宽泛的 `allowed-tools`、免审批部署权限或虚构依赖。Claude Code 使用相同 SKILL.md，不依赖某个宿主专属的动态命令语法。
