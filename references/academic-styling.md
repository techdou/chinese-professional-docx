# 中文硕士论文式黑白排印：代码与表格

## 定位与规范层级

通用文档以清晰、克制、可黑白打印的中国学位论文式排版为视觉参考，并不等于自动满足特定学校的正式提交要求。优先级：本次提供的学校/机构官方 Word 模板 > 用户明确的样式约束 > 本 Skill 通用默认值。读取官方模板后才可判断页眉、边距、章序、字体、封面等是否符合要求。

参考来源：公开发布的高校研究生学位论文写作规范正文及其自然科学、人文社科官方模板附件（已实读核对；不入库、不列具体院校）；GB/T 7713.1—2025 为现行国家推荐性学位论文规则；其他国内院校规范通常推荐三线表。已确认两个编号范式以及三线表 1.5/1 pt 的写法；未将任何院校的专属规则强制套用于一切文档。

## 默认设计

1. 白底黑字。正文、标题、表格与信息注释不设置彩色强调线、色块或底纹。保持原有正文/标题字号与段落缩进基础，不悄悄切换其他学校的边距、页眉或封面。
2. 代码段：仅明确标记为 `代码段`/`Code Block`/`CodeBlock` 的段落使用浅灰 `#F5F5F5` 段落底纹、黑色字、不加竖边线；英文字体保留原等宽字体，中文保留原东亚字体；换行/空格/Tab 不得因为修复而丢失。代码块不是正文，不套两字符缩进。
3. 数据表默认三线表：黑色顶底线各 1.5 pt，表头分隔线 1 pt，纵线和内部横线默认关闭；首行重复表头；表题在上。表内黑字白底，不加灰表头、交替颜色。
4. 复杂表显式允许 `grid`，图例/对齐表可用 `none`；不强制一刀切。表格跨页若需要“续表”及重新编号，须在 Word 终稿中逐页处理。
5. 全文黑白不等于删改官方封面校徽。学校官方封面、著作权声明等优先保留原样，不进行自动黑白化。

## 标题与多级编号

新建正式文档默认根据场景使用三级标题编号；Word 原生字段而非写死文字。通用报告采用“一、（一）1.”，自然科学/技术论文采用“1/1.1/1.1.1”，章节型技术论文采用“第1章/1.1/1.1.1”，人文社科采用“第一章/一、（一）”。允许 `none`、指定学校模板优先。详见 [heading-numbering.md](heading-numbering.md)。

## 代码和表格的明确调用

`new --brief` 遇到 `code` 块自动赋代码样式与底纹，遇到 `table` 块默认生成三线表。特殊表格在 brief 的 table block 中加 `"style": "grid"` 或 `"style": "none"`。

`format-code INPUT --out OUTPUT` 仅修已标记代码的段落，可额外通过 `--style 名称` 选中自定义代码样式。`format-tables INPUT --out OUTPUT` 默认仅修已经指定 AcademicThreeLine 样式的表格，其他表格必须显式 `--all` 才处理。所有修改写新副本。

这些参数是可复用的视觉默认，不应伪称某所学校的强制磅值。具体论文按官方模板执行。

## 已知边界

- 默认 `SEQ Table` 题注为全文顺序编号；院校若要求“表 3.2”式章节编号或续表，应在正式稿中按其规范处理，不能声称由 brief 自动实现。
- 合并单元格、表格内图片、嵌套表格或全跨页的长代码块：先测试后处理，逐页核验边框重复、分页、内容保真。
- `format-code` 不凭内容猜测哪段是代码；未正确套用样式时，需要使用者先分类或指定匹配的段落样式。
- 字体嵌入依赖 Windows Word COM 与有许可的本地字体；本次格式升级不修改字体嵌入流程。


## 表格与引用的联动（v1.6）

三线表仍为默认；图表按章 `1-1/1.1` 编号、正文上标数字引文、图表/公式可更新交叉引用也成为推荐范式。`explicit-chunks` 生成物理续表并重复表头；`repeat-header` 仅让 Word 按自然分页重复表头，不能自动生成“续表”段落。优先遵守用户或学校指定模板。[完整说明](references-and-long-tables.md)。
