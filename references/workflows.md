# 创建与场景选择

通用：assets/templates/base.docx 为短文档起稿；按需添加标题、概述和分节，不强制论文结构。new 复制模板不会把占位文字变成真实内容。

讲义：assets/examples/handout.docx 演示目标、概念、例子、练习与反馈；根据学习者调整内容。代码、表格和步骤保留独立样式，不强制加摘要或学位论文声明。

竞赛：assets/examples/competition.docx 可参考问题、方案、创新、实施和产出。先看是否有赛方指定模板、字数/匿名要求；有指定模板时不使用这个场景文件替换。缺少预算、成果和指标明确待补，不编造。

报告：assets/examples/report.docx 演示背景、进展、证据、问题和计划；区分已完成、进行中和拟开展，不把计划写成验证结果。

组件：assets/examples/components.docx 展示正文、标题、清单、表格、提示、代码与题注，只取实际需要的部分。不要为展示组件向完成稿添加无关章节。

已具备内容时，按 brief 契约组织 blocks，先 validate-brief 再 new。内容不完整且允许写作时，依照用户给定来源撰写，未知事实标记待补；仅排版任务不可扩写。

沿用当前工作区目录，只在多产物任务中适度分类。不要重整无关文件，不将通用排版调用当作 GitHub 发布或邮箱发送授权。
