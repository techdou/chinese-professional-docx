# 样式规则与取舍

## 规则优先级

先满足用户本次明确约束和正式提交模板；默认排版用于未指定的部分。发现“正式模板要求不缩进”与“用户要求两字符”冲突时，应点明具体冲突再确认，不自行决定提交规则。没有正式模板时，本 Skill 默认普通正文每段首行缩进 2 字符。

本包保留内置通用母版的页面、字号、首行缩进及字体基础参数；v1.3 的视觉层参考传统中文硕士学位论文的黑白排印风格，**不是任何院校的正式提交母版**，也不覆盖学校已指定的 DOCX/DOTX。详见 [academic-styling.md](academic-styling.md)。

## 通用默认值

| 对象 | 默认值 |
| --- | --- |
| 纸张 | A4 纵向，210 × 297 mm |
| 页边距 | 四边 2.5 cm；无装订线 |
| 正文 | 宋体 12 pt，西文/数字 Times New Roman 12 pt；两端对齐 |
| 正文段落 | 首行缩进 2 字符；1.5 倍行距；段前 0 pt，段后 4 pt |
| 文档主标题 | 黑体 20.5 pt，加粗，左对齐；纯黑、无彩色装饰线 |
| 一级标题 | 黑体 15.5 pt，加粗，左对齐 |
| 二级标题 | 黑体 13.5 pt，加粗，左对齐 |
| 三级标题 | 黑体 12 pt，加粗，左对齐 |
| 标题编号/分页 | 新建正文标题默认 Word 原生三级多级编号；场景自动选 `chinese-formal`/`academic-decimal`/`academic-chapter`/`humanities`；允许 `none`，不强制每章换页 |
| 图表题注 | 宋体/Times New Roman，10.5 pt，居中 |
| 表内文字 | 独立的“表格正文”，通常 10.5 pt，不首行缩进；黑字、白底 |
| 表格 | 默认学术三线表：黑色顶底线各 1.5 pt、表头线 1 pt；表题在上，跨页重复表头；不设竖线、表头色块与斑马纹 |
| 紧凑正文 | 独立紧凑行距及字号，但仍首行缩进 2 字符 |
| 代码 | 独立等宽字体样式，黑字与中性浅灰 `#F5F5F5` 段落底纹；无彩色左侧边线，保留代码缩进/换行，不套正文缩进 |
| 参考资料 | 独立悬挂缩进，不强制转为普通正文 |
| 页眉页码 | 空白页眉；自动阿拉伯数字页码，底部居中 |

`assets/style-profile.json` 是**部分**检查（如标题尺寸表）的机器配置；Normal 的字号/字体/行距/对齐与页边距检查的期望值目前硬编码在 audit 实现里，修改 profile 不会改变这些项（见 audit-rules.md §5 已知限制）。普通模板中保留的 `Body Text 2/3` 是兼容样式，并不表示所有例外字号/行距都要强制变成 Normal。

**标题系统**：编号用 Word 原生 `abstractNum/num` 与 Heading 1–3 关联，不在标题文字中写死序号；特殊前后置章节按需不编号，旧文档默认不动。详见 [heading-numbering.md](heading-numbering.md)。

**视觉系统**：以白纸黑字为主，只允许代码段使用浅灰底纹。黑白打印时三线表边界需清晰且不喧宾夺主。部分表格因合并单元格、复杂层次或特殊统计说明需要辅助线，可显式选择 `grid`；不能把三线表当作任何学校无例外的强制规定。

这些值是工作默认值，不是国家标准、学校或赛方的统一强制数值。用户明确要求标准字号 16/14 pt、不同页边距或正式文档主标题时，可在副本中调整相关样式并记录；不得改变正文两字符规则，除非本次有明确例外。

## 两字符缩进的实现

12 pt 正文的关键 OOXML：

```xml
<w:ind w:firstLineChars="200" w:firstLine="480"/>
```

字符单位按百分之一字符计，因此 200 表示两个字符。长度后备值使用 twips（1 pt = 20 twips）；普通中文全角字近似按字号计算，12 pt × 2 × 20 = 480 twips。字体大小不同，应更新后备值，而非把所有正文样式硬编码成 480。`python-docx` 的长度型 `first_line_indent` 不能单独表达真正的字符单位，需设置原生 XML 属性。[实现依据见 sources.md 的 S4–S5]

设置前先检查并消除正文中冲突的 `hanging/hangingChars`、直接零缩进以及伪缩进。样式和现有段落都要查；只改 Normal 会漏掉直接格式覆盖。修改共享的 Normal 样式时，还要防止表格、页眉或特殊样式意外继承两字符。

不要把 `left_indent` 设为两个字符当作首行缩进；那会移动整段。正文段落必须用段落分隔，不用连续空格或软回车模拟。

## 字体、公式与混排

为东亚文字设置 `eastAsia=宋体`，为西文设置 `ascii/hAnsi=Times New Roman`；核对主题字体与直接格式，避免它们覆盖期望结果。字号、加粗和斜体的有意强调应保留，不能用“清除全部格式”破坏语义。

公式使用宿主支持的原生公式或可靠公式工具；数学字体/符号不是普通英文正文，不能强行全部改成 Times New Roman。此包的 JSON 生成器不声称支持复杂公式、嵌套表格、嵌入对象或有修订的内容重建。

未安装宋体、黑体、Times New Roman 时可能发生替代渲染。保留文档中的期望字体名称，说明当前机器缺字体，在最终设备核对。~~包内不提供字体文件。~~（废止于 2026-10-30：`assets/fonts/` 已收录本机 12 件中英文字体供预览注册与文档嵌入，见 SKILL.md"字体资产"节；仅本机使用、不随交付物分发。）
