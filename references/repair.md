# 只修缩进

1. 读取输入，确认允许改动的范围。运行 `audit INPUT --scope indent --details`，角色表会给出段落序号、样式 ID/名称和有效缩进，不复制正文到报告。
2. 普通正文才进入修复。未知样式先阅读对应段落；确认为正文后可用 `--body-style "样式名或ID"`，不能把所有未知样式批量当正文。
3. 运行 `fix-indent INPUT --out NEW_OUTPUT`。保留文字、公式、域、超链接及原文件，输出必须是新路径。只有确认开头空白是伪缩进后，才加 `--strip-manual-padding`。
4. 用同一个 `--scope indent` 及相同的 `--body-style` 复查。`--strict-review` 会在仅有警告时退出 3，要求处理警告；不能把它改成通过。
5. 对比前后正文、关键数字、链接、域和非正文对象，再渲染逐页查看。二次修复若无变化应报告无需进一步修改，不虚报修复数量。

边界：正文以“1.5 倍”“2.0 版”等小数开头不能自动当列表。真正手工列表、含公式或图片的段落、内容控件、未知样式需确认角色。手工空格清理只读真实段首，遇到超链接、域或内容控件立即停止，不能跳过它们再删中间空白。

签名、保护、任何已检测到的修订内容会阻止自动修复/转换；不自动接受修订、删除签名或解除保护。页眉、页脚、脚注、尾注、批注即使使用 Normal 也不是主文正文。脚本不是完整 Word 渲染或 OOXML 合规引擎；复杂样式冲突用宿主工具处理后重验。
