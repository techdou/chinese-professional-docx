# GB/T 7714—2025：文献著录与正文标引引擎

> 维护规则基于现行 GB/T 7714—2025（2025-12-02 发布，2026-07-01 实施，代替 2015 版）、学校模板与权威公开资料。**这是规范化默认机制，不是全场景强制模板。** 学校、期刊或用户指定规范优先；规则条文和书目信息不能凭标题猜测。
>
> 官方标准入口：[国家标准信息平台](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14)。详细规则以正式标准全文及最新投稿须知为准，本文不是标准原文替代品。

## 1. 范式优先级

1. 明确的用户目标、学校/期刊官方 Word 模板、投稿格式及学科差异。
2. 中国正式文档常用默认：GB/T 7714—2025、顺序编码制、正文数字方括号上标、文后书目按首次引用顺序排列。
3. 作者—出版年制、数字行内制等为**可选范式**；不能假定所有单位都规定上标。
4. 无法验证的出处、作者、卷期、页码、版本、引用日期、DOI 等应报告缺失，不得臆造。

## 2. 版本与兼容分流

`reference_standard` 取值：

- `gbt7714-2025`（默认）：允许受支持的结构化核心文献元数据格式化；同时容纳 `text` 已排版条目，但会发出 **preformatted-unverified** 警告。
- `gbt7714-2015-compat`：仅接受使用者已经核对、提供的完整 `text`，不假装用 2025 的格式引擎生成 2015 版。
- `institution-custom`：学校或期刊要求覆盖通用标准时，同样采用事先核对的 `text` 及独立适配；不可暗改正文。

`citation_mode` 取值：`numeric-superscript`、`numeric-inline`、`author-year`。后二者分别适用于行内数字制、著者—出版年制。

## 3. 数据接口

一个条目使用稳定 `id`（英文 ASCII 字母开头，字母、数字、下划线、点、短横线）。**不得在条目 `text` 中手写 `[n]` 序号**。

### 3.1 原样已校验条目

```json
{"id":"checkedRef","text":"作者. 已核实的文献题名[J]. 已核实的期刊, 2025, 12(3): 1-8."}
```

旧文档的兼容性最好；但工具无法从原样文本推导作者、年份或核实元数据，所以它不能用于 `author-year` 模式。

### 3.2 结构化条目（格式测试示例，非真实文献）

```json
{
  "id":"demoDataset", "type":"DS", "title":"测试用遥感数据集",
  "authors":["示例机构"], "version":"V2.0", "platform":"示例数据仓库",
  "published_date":"2026-01-05", "accessed":"2026-11-02",
  "url":"https://example.org/dataset"
}
```

当前核心格式覆盖九类：`J`（期刊文章）、`M`（图书）、`C`（会议文献）、`D`（学位论文）、`R`（报告）、`S`（标准）、`EB`（网页）、`DS`（数据集）、`PP`（预印本）。另外识别标准 A.1 文献类型代码，但对 `N/P/A/CM/G/CP/DB/Z` 等尚未实现独立、可保证语义准确的著录模板：**不能把识别类型等同于完成该类格式化**，需要经审校的 `text` 或扩展模板。

所有 `url` 均应来自真实来源；网络资源校验访问路径、引用日期等项目。已含 DOI 的访问路径不再重复列 DOI。没有出处的条目、未检索确认的作者与年份不得臆造补齐。

### 3.3 九类核心项目分流

| 代码 | 自动化最低要求 | 进一步人工核对 |
| --- | --- | --- |
| `J` | title、container、year | 卷/期、页码/文章编号、作者、DOI、online 状态 |
| `M` | title、place、publisher、year | 版次、卷次、页码、作者 |
| `C` | title、conference、conference_year | 会议名称与会议录/析出论文关系、页码 |
| `D` | title、institution、place、year | 授予学位信息、年份、引用页码 |
| `R` | title、year | 报告来源、发布者、报告编号 |
| `S` | title、standard_number、year | 发布/实施信息、正式标准编号 |
| `EB` | title、url、accessed | 发布与更新日期、网站/网页主体 |
| `DS` | title、url、accessed | dataset version、发布平台、发布日期 |
| `PP` | title、url、accessed | preprint version、发布平台、正式发表状态 |

字段“最低要求”是本 Skill 的保守输入验证契约，**不等于标准每个条目都仅需这些字段**；还须结合第 7—8 章与原始来源判断“必备”“有则必备”“可选”。

## 4. 正文交叉引用契约

正文只允许显式 ID，不猜数字。

| 标记 | 数字制显示（示意） | 实现 |
| --- | --- | --- |
| `[[CITE:a]]` | 上标 `[1]` | `SEQ CPBibliography` + 书签 + `REF` |
| `[[CITE:a;b;c]]` | 连续编号时上标 `[1-3]` | 只保留端点 `REF`，作者时生成范围分组 |
| `[[CITE:a;c]]` | 非连续时上标 `[1,3]` | 各 `REF` 独立更新 |
| `[[CITE:a@23-25]]` | 上标 `[1]23-25` | 页码位于方括号外，可编辑 |
| `[[FIG:flow]]` | `图1-1` | 图表题注 `SEQ` + `REF` |
| `[[TABLE:comparison]]` | `表1-1` | `SEQ` + `REF` |
| `[[EQ:loss]]` | `式（1-1）` | `SEQ` + `REF` |
| `[[PAGE:flow]]` | `2` | `PAGEREF` |

`author-year` 会生成中文括号中的作者+出版年引用，例如“（张示例，2025）”。同作者同年多项通过标题字典顺序稳定赋 `a/b/c`；中文排序不一定等于各机构要求的拼音排序，正式稿应核对。为了保留 Word 可更新的 `REF`，在书目条目前创建了不可见的引用标签书签，书目正文仍是普通可编辑文字。

### ⚠️ Word 域的真实边界

Word `F9` 只重新计算数字字段，不会自动改变本 Skill 已建立的**区间分组**或重排整个文献表。文稿若新增/删除/移动正文引文，必须从结构化 brief 重新生成/重排书目，再在 Word 中刷新字段，随后复核每一处 `[1-3]`。不能仅凭 `Ctrl+A,F9` 声称语义排序始终正确。

通过的验证仅证明 OOXML 字段和书签结构符合本工具的契约；Word/WPS 原生更新、链接跳转和分页须在真实宿主测验，LibreOffice 渲染不替代原生验收。

## 5. 命令、审计与异常策略

```bash
python scripts/docx_ops.py audit-bibliography assets/examples/brief-gbt7714-2025.json --strict-review
python scripts/docx_ops.py validate-brief assets/examples/brief-gbt7714-2025.json
python scripts/docx_ops.py new --brief assets/examples/brief-gbt7714-2025.json \
  --out academic.docx --manifest-out academic-refs.json
python scripts/docx_ops.py audit-references academic.docx --strict-review
python scripts/docx_ops.py link-references edited.docx --manifest academic-refs.json \
  --out edited-linked.docx
```

所有输出均新路径，不覆盖原件；`link-references` 用 manifest 自动识别数字或作者年份模式，不允许与显式错误模式混用。既有 DOCX 中文本相似的 `[1]` 或“图1-1”**不会**被猜测自动连接。标记跨 Word run、缺目标、重复 ID、缺关键字段会失败并提示核实。

`audit-bibliography` 的 warning 与 error 应分别检查：

- **error**：缺失必要字段、非法日期、非 HTTP(S) URL、重复 ID、结构化类型尚不支持、旧文本误用在 author-year。
- **warning**：原样文献未验证、可选但可能存在的版本/平台未录入、电子资源日期需复查、来源作者信息不足。

真实引文语义质量还需文献库或期刊数据库对照，工具不联网抓取、不杜撰。

## 6. 完成标准（DoD）

1. 参考文献在正文首次出现的顺序与文后数字编号一致；相同 ID 始终同号；上标仅在对应场景出现。
2. 连续与非连续组、重复引文页码、作者同年多文献、网络标识符去重均有代码测试。
3. 校验不过不写 DOCX；已完成稿能以 `audit-references` 检出缺书签/悬空 REF。
4. 与标题、图表、三线表、浅灰代码块和既有完整母版的回归测试通过。
5. Windows Word/WPS 原生更新、跨页续表和嵌入字体未测时必须标记 `pending`。
