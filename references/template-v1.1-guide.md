# 中文通用专业文档 Word 母版（2026）

## 定位

这是一套**非论文专用**、可直接复用的简洁 Word 排版母版，面向竞赛申报／作品说明、课程讲义／培训资料、项目报告／阶段总结、学术报告、会议材料等。它是在此前高校硕士论文适配版基础上**重新设计**的通用版本，不是任何院校或单位的官方模板，不包含学位论文专属约束。

## 文件说明

- `01_通用母版/中文通用专业文档_即用版.docx`：替换标题和少量占位文字即可撰写；默认不强制章节结构。
- `01_通用母版/中文通用专业文档_可复用母版.dotx`：真正的 Word 模板，可反复“从模板新建”以避免覆盖母版。
- `02_场景示例/排版样式与组件_示例.docx`：展示标题、正文、列表、提示、代码、表格、图片和参考资料等格式。
- `02_场景示例/竞赛项目材料_示例.docx`：演示参赛说明书 / 项目书的常见结构（**非赛方官方表格**）。
- `02_场景示例/课程讲义_示例.docx`：演示教案式讲义、关键概念、操作与课堂练习（**不限制学科**）。
- `02_场景示例/项目报告_示例.docx`：演示阶段总结、任务追踪与风险计划。

## 正文每段首行缩进 2 字符（v1.1 起默认）

- **新建正文段落自动生效：** “正文 / Normal”是默认段落样式，设置了“特殊格式 → 首行缩进 → 2 字符”。连续输入正文时，每次按 Enter 新建的普通正文段落也自动缩进。
- **不是键入两个全角空格：** 采用 Word 原生的**字符单位缩进**（OOXML `firstLineChars=200`），另设 24pt 作为不识别字符单位的办公软件的显示后备值；无需在行首键入空格或 Tab。
- **普通叙述段落均一致：** `Normal`、`Body Text` 系列、`紧凑正文`及兼容保留的`正式正文（首行缩进）`均采用 2 字符缩进。
- **特殊段落不盲目缩进：** 各级标题、标题页信息、项目符号与编号列表、图题表题、表内单元格、代码块、提示框、图片占位、练习标题保留各自对齐规则；参考资料继续采用悬挂缩进。
- **核查方法：** 将光标放在任意普通正文段落中，Word“开始 → 段落 → 缩进和间距”，应显示“特殊格式：首行缩进；缩进值：2 字符”。不同版本 Word/WPS 的入口可能略有差异。
- **粘贴内容时：** 推荐“只保留文本”或“合并格式”再应用“正文”样式，避免从外部文件带入手工空格或独立段落缩进覆盖模板设置。

## 推荐用法

1. **最快起稿：** 打开即用版 `.docx`，替换方括号占位内容；不需要的块直接删除。不要把“示例文字”写入正式交付稿。
2. **以后重复使用：** 双击 `.dotx` 从模板新建 Word 文档，保存为新的 `.docx`。不要把母版改成唯一工作底稿。
3. **换场景：** 竞赛、讲义、报告分别打开对应示例，复制需要的段落 / 表格到即用版即可；最终只保留你实际需要的内容。
4. **统一格式：** 在 Word/WPS 的“开始 → 样式”里使用 `Normal（正文）`、`标题1`、`标题2`、`标题3` 等；普通正文默认自动首行缩进 2 字符。若要改变段落外观，应修改样式，而非逐段手调或手动输入空格。
5. **目录是可选的：** 长报告需要时使用“引用 → 目录 → 自动目录”；模板使用 Word 标准标题层级以支持自动生成。短讲义与竞赛说明书可不插入目录。
6. **题注：** 示例中表号 / 图号使用 Word 的 `SEQ` 字段；复制后在 Microsoft Word 里执行 Windows `Ctrl+A → F9` 或 Mac `⌘+A → fn+F9`（视键盘设置），并核对编号；新增图表更推荐“引用 → 插入题注”。LibreOffice/WPS 的字段兼容性可能不同。
7. **需要不同页边距：** 在“布局 → 页边距”按主办方／院系要求修改；本母版不保留学位论文适配版原专用页边距。
8. **跨设备：** 已分别设置中文字体与英文字体。若电脑没有宋体/黑体/Times New Roman，Office/WPS 会使用替代字体，打印前应在最终机器检查分页并导出 PDF 复核。

## 设计原则与边界

- **不包含**学校专用封面、独创性声明、匿名评阅页、学位授权书、强制中英文摘要、固定论文后记等内容。
- **不要求**从第1章开始、不预设研究方法/实验/结论的固定章节顺序；通用文档可以不编号。
- **提供但不强制**项目符号、编号列表、图表、练习任务、代码片段、参考资料与目录功能。
- 示例文档中所有方括号内容均为占位，所有项目名称、计划和指标均未声明真实已完成。
- 文件设计日期：2026-10-13。版本：v1.1（普通正文默认首行缩进 2 字符）。
