# 学校或赛事指定模板

先读取当前提供的模板、规范及用户允许的修改范围。优先使用已提供的原件；只有确需核实最新规范且缺少资料时检索官方来源。不能把旧对话中的学校参数说成现行要求。

把与任务相关的约束记录下来：纸张/分节、正文/标题样式、字号/缩进、页眉页码、封面或固定表格、字数/匿名信息等。只记录实际核验项目，不强迫每份材料都检查所有学校规则。

以指定模板为底稿，保留其版式、内容控件和固定页。不使用 `new --scene` 或通用 brief 生成器重建正式模板。若仅需要两字符缩进且它与指定规范一致，用 `audit --scope indent` 和保守修复；通用 `audit` 的页边距或字号警告不是机构“不合格”结论。

优先级：用户已经确认的局部任务与正式模板约束 → 通用默认。两者明确冲突又会影响提交时才问一个必要问题，不静默覆盖任何一方。

交付时区分“完成授权的排版调整”与“已逐项验证机构合规”。本 Skill 没有任何院校官方认证；参照其学术风格的通用文档也不是学校学位论文模板。
